# DockPin

macOS moves the Dock to your external monitor whenever the cursor touches the bottom of that screen, and has no setting to stop it; DockPin keeps the Dock on your MacBook's built-in display.

## Setup

```bash
git clone https://github.com/andrewjdarley-andera/DockPin.git
cd DockPin
./install.sh
```

When System Settings opens, turn on **DockPin** under Privacy & Security > Accessibility.

To remove it, run `./uninstall.sh`.
